# hex-maven

Static Maven repository (served by GitHub Pages) with the intermediate build artifacts that the
unofficial, AI-assisted Minecraft 1.21.1 ports of Hex Casting, Hexal, MoreIotas, wnboi and HexGloop depend on.

**These are unofficial AI-assisted builds of the 1.21.1 ports, not official releases.** Sources live in the
forks at https://github.com/y9dev (`port/1.21.1` branches). The original projects belong to their authors.

Repository URL: `https://y9dev.github.io/hex-maven/`

Groups: `at.petra-k.hexcasting`, `ram.talia.moreiotas`, `ram.talia.hexal`, `com.samsthenerd.wnboi`.
Versions are immutable; do not overwrite published versions.
